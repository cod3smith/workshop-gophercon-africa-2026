## Design specificity verdict

The game is authored for this product; the home page below the hero is interchangeable.

Authored: the eye-in-grass mark; clues() withholding species and place as the mechanic; geographic verdict vocabulary; a documented scoring curve whose e-folding distance was chosen so continent knowledge still scores.

Interchangeable: the .record section - 60 photo-over-caption cards above a four-figure stat strip, with no coordinates, micro-map, weather or link to the record.

Deterministic scan: 1 CLI finding, overused-font (Inter) at web/views/layout/layout.templ:34. In-page across five pages: hero-eyebrow-chip and italic-serif-display on /; all-caps-body on every page (layout chrome); cramped-padding x2 and undersized-ui-text x2 inside Leaflet's attribution control.

Agreement without contact: the hero eyebrow - flagged by the detector, banned by the craft floor, and noted by the design review.

False positives verified and discarded: buried-raster x8/x15 (Leaflet fade caught mid-paint; 14->6 and 21->6 on settled pages); text-occlusion x9 (detector flagging its own overlay on second injection); one desktop overflow reading taken with the overlay attached. Leaflet attribution findings are third-party chrome required by OSM's licence.

Overlays were injected on all five pages and read from the console; the live server was then stopped, so no overlay is currently visible.

## Overall impression

The middle is excellent and both ends are weak. The round-and-reveal loop is well made. Either side sits a home page that never explains the game and an ending that insults the player and cannot be shared. Biggest opportunity: the finish.

## What's working

1. Token system has reasons that survive measurement - gold nowhere decorative, two edge weights, control bound clears 3.05:1, all text above 4.6:1, colour never the sole carrier.
2. Three input routes to the map, with crosshair and centre button revealed only once Leaflet is live.
3. Defensive game logic: replay token, coordinate wrap, reseed redirect, empty state naming the exact command.

## Priority issues

### [P0] No way to answer without a working map
Crosshair position is never announced, so a screen-reader user can place but not aim. Same gap blocks anyone whose CDN is filtered: no Leaflet means no crosshair, no centre button, permanently disabled submit. No lat/long input exists.
Fix: announce crosshair on moveend into a polite live region; add optional visible lat/long number inputs bound to the hidden fields, which also gives a no-JS path. Command: /impeccable harden

### [P1] On a phone the evidence and the control are never co-visible
At 375x812: photo bottom y=532, map top y=994, with the clue panel and a 45-word hint between.
Fix: under 60rem reorder photo -> map -> clues, cap the plate to 16:9, collapse clues to a chip row, sticky submit bar. Command: /impeccable adapt

### [P1] The game crops the evidence it scores you on
.plate__photo is object-fit: cover, cutting horizon, edge vegetation and sky. All images site-wide are 2048px originals, 60 on /, no width/height, no srcset.
Fix: object-fit: contain on a letterboxed plate; medium/large variants; intrinsic dimensions. Command: /impeccable optimize

### [P1] Raw database strings in the panel the player reads
Mammalia; "State of sky on the whole unchanged" (SYNOP code); a credit rendering as MALACOCHERSUS over an impala - broken attribution promise and a potential answer leak.
Fix: map classes to plain English; whitelist weather descriptions and omit rather than print code; reject credits matching the sighting's own genus. Command: /impeccable clarify

### [P2] The ending punishes and does not travel
First plays land on "Hopelessly Lost"; Share() carries no URL, so the one spreading mechanism dies on paste.
Fix: URL in the share line; rename the bottom bands; headline the best round; put the five true locations on one map. Command: /impeccable delight

## Persona red flags

First-time visitor: never told the rules; both hero buttons same size; 60 tiles with link affordances that go nowhere; "Wrong planet, almost" at 5,781 km reads as a sneer before rapport exists.

Keyboard / screen-reader: no h1 on /play; tab order puts two off-site attribution links between the map and submit; verdict is a p, so no landmark after submitting; focus lands at document top each round.

Conference attendee on a phone: four third-party origins before the game works; 60 originals with no intrinsic dimensions; ten scrolls per game; share line with no link.
